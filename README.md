# 수원 신고가 브리핑 🔥

수원시(장안구·권선구·팔달구·영통구) 아파트 실거래를 자동 집계해서

1. **웹페이지**(GitHub Pages)에 보여주고,
2. 매주 **월·목 오전 8:30(KST)** 에 아파트 커뮤니티 **아파트너에 자동 게시**하는 프로젝트입니다.

브리핑 구성 (페이지·게시글 동일):

1. 🏠 **우리 아파트** — 최근 거래가 + 면적형별 신고가(역대 최고)
2. 🏘 **인근 단지 신고가** — 같은 정자동 단지들의 면적형별 역대 최고가
3. 📈 **오늘의 수원 신고가** — 최근 계약 중 새로 나온 신고가 전체 목록

우리 아파트·인근 단지 기준은 `config.json` 에서 변경할 수 있습니다.

### 게시글 형식

아파트너 글은 **이미지 카드 한 장**이 본문 역할을 하고, 글에는 핵심 수치 몇 줄만 남깁니다.
`config.json` 의 `post.bodyMode` 로 바꿀 수 있습니다.

| 값 | 게시 형태 |
|---|---|
| `image` (기본) | 요약 4~5줄 + 이미지 카드 1장 |
| `full` | 우리 아파트·인근 단지·오늘의 신고가를 모두 텍스트로 나열 + 이미지 카드 |

데이터 출처: 국토교통부 실거래가 공개시스템 (공공데이터포털 API)

## 신고가 기준

- **같은 단지 · 전용면적형(㎡ 정수 절사 기준)별 역대 최고 거래가** (예: 84.94㎡와 84.78㎡는 같은 "84형")
- 해당 면적형의 첫 거래는 `신규`로 표시
- 해제 신고된 거래는 제외. 실거래 신고는 계약 후 최대 30일 지연될 수 있어 매 실행 시 최근 3개월치를 다시 확인합니다.

### 직전 실거래가 병기

역대 최고가는 몇 년 전 기록인 경우가 많아(예: 84형 최고가는 2021년) 그 값만으로는
지금 시세를 알 수 없습니다. 그래서 면적형별로 **최고가를 넘지 못한 가장 최근 거래**를
`직전 8억7천` 처럼 함께 적습니다. 최근 거래가 곧 최고가면(=신고가) 중복이라 적지 않습니다.

우리 단지는 전체 거래 이력이 있어 항상 나오고, 인근 단지는 조회 범위(최근 3개월) 안에
거래가 있을 때만 나옵니다.

## 수동 실행 옵션

Actions → Run workflow 에서 고를 수 있습니다.

| 입력 | 하는 일 |
|---|---|
| `backfill` | 과거 실거래 전체 적재 (최초 1회, 20~30분). 중단돼도 진행분이 남아 이어서 실행됩니다 |
| `reset` | 백필 전 최고가 DB·진행상태·게시이력 초기화 (`backfill`과 함께) |
| `post` | 끄면 데이터 갱신만 하고 게시하지 않습니다 |
| `dry_run` | 게시 리허설. 데이터를 건드리지 않고 제목·본문·이미지·등록 버튼까지 확인한 뒤 **저장을 누르지 않고** 끝냅니다 |
| `force_post` | 지금 저장된 리포트를 새 신고가 탐지 없이 **그대로 실제 게시**합니다 |

같은 제목의 글이 이미 게시판에 있으면 다시 올리지 않습니다. 게시 성공 여부는
저장 버튼 클릭이 아니라 **목록에서 글이 보이는지**로 판정합니다.
